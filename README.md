├── index.html        # 首页（含知识库四板块、出版专著、AI Demos、关于）

## 如何更新

1. 编辑 `index.html`
2. 提交并推送到 `main` 分支：

```bash
git add -A
git commit -m "update site"
git push origin main
```

GitHub Pages 会在几分钟内自动发布。
